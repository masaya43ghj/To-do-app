# Apps Script

このディレクトリには Google Apps Script を置いています。

## decluttering-lunch-survey.gs

「おしゃれ断捨離 ランチ会」参加者向けのアンケート用 Google フォームを自動生成するスクリプトです。

### 質問項目

| # | 質問 | 形式 | 必須 |
|---|------|------|:----:|
| Q1 | お名前 | 短文 | 任意 |
| Q2 | 今日のランチ会はいかがでしたか？ | 5段階評価 | 必須 |
| Q3 | 特に楽しかったこと・印象に残ったこと | 段落 | 必須 |
| Q4 | 「もっとこうだったら」という改善点 | 段落 | 任意 |
| Q5 | 今後やってみてほしい企画 | 段落（例つき） | 任意 |
| Q6 | 一言メッセージ | 段落 | 任意 |

### セットアップ手順

1. [Google Apps Script](https://script.google.com) で新規プロジェクトを作成する
2. `decluttering-lunch-survey.gs` の内容を貼り付ける
3. `createForm` 関数を実行する（初回は権限承認が必要）
4. 実行ログに出力される **編集用URL** / **回答用URL** を確認する
